- Loading prepared single-run adapter context.
- Multi-testbench child context.
- Corner-aware child context.
- Formula/request hash drift rejection.

- CSHRC command wrapping behavior.

### Helper Compatibility Is Required

- `_create_ready_corner_project` is imported by:
  - `tests/test_real_run.py`
  - `tests/test_remote_spectre_ocean.py`
  - `tests/test_remote_spectre_ocean_waveform.py`

Keep the helper name and signature:

```python

```

Do not require consumer changes for R5.

### Generic Project Factory Is the Source of Truth for Single-Run Adapter Projects

Use:

```python
from tests.project_factory import create_approved_generic_project
```

Replace `_create_ready_real_run_project` so it no longer calls `create_project_from_template()` or writes `TEMPLATE_TEXT`.

The helper should:

1. Build an approved generic project.
2. Prepare `real_001`.
3. Return the project directory.

Suggested shape:

```python
def _create_ready_real_run_project(tmp_path: Path) -> Path:
    project_dir = create_approved_generic_project(
        tmp_path,
        name="spectre_ocean_adapter_project",
        created_at_utc="2026-06-02T00:00:00Z",
        max_evaluations=12,
    )
    prepare_real_run(project_dir, created_at_utc="2026-06-02T00:20:00Z")
    return project_dir
```

If a test needs exact Spectre settings, derive expected values from the request/config generated by the project rather than hardcoding old packaged-template values.
